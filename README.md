# React Contact Cards Manager

A SPA for creating and displaying contact cards with live search.

## Structure

```bash
react-contact-cards-manager/
├── public/
├── src/
│   ├── components/
│   │   ├── ContactForm.js
│   │   ├── ContactCard.js
│   │   └── ContactList.js
│   ├── App.js
│   ├── index.js
│   └── styles.css
├── index.html
├── package.json
├── vite.config.js
└── README.md
```

## Run

```bash
npm install
npm run dev
```
